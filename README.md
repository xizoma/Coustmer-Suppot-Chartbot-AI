# AI Customer Support Chatbot

## Overview
AI Customer Support Chatbot is a web-based chatbot application that helps users with customer support queries such as:

- Order Tracking
- Refund Requests
- Product Information
- General Customer Assistance

## Features
- AI-powered responses
- Order ID checking
- Refund assistance
- Interactive chat interface
- Simple and user-friendly design

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
